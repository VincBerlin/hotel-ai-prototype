# GOAL-guest-journey-touchpoints: Guest journey touchpoints

**Description**: Curt AI engages guests across the full stay arc — pre-arrival, check-in day, and during stay — delivering contextually appropriate messages and interactions across multiple channels (web chat, WhatsApp, Instagram DM).

**Status**: Draft

**Priority**: Should-have

**Source stakeholder**: [STK-hotel-guest](../stakeholders.md)

## Success Criteria

- [ ] The system supports three distinct guest journey phases: pre-arrival, check-in day, stay
- [ ] Each phase surfaces relevant contextual information (booking details, local tips, hotel facilities)
- [ ] The chat interface reflects the current journey phase and adapts its context accordingly
- [ ] Multi-channel touchpoints (WhatsApp, Instagram) are representable in the UI prototype
